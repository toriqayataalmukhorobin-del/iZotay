# iZotay v0.1.0 — Preview

Rilis preview publik pertama iZotay, editor desktop lokal untuk dialog dan audio dari video.

## Isi rilis

- Editor timeline multi-track dengan waveform, seleksi, marker, split, trim, fade, crossfade, undo/redo, dan playback.
- Kontrol restorasi track, A/B, preset `.izopreset`, batch processing, gain automation, dan bleed reduction.
- Audio dari video dapat diedit dan diekspor ke MP4 baru tanpa menimpa video sumber.
- Sesi `.izotay` serta paket preview untuk Linux x64, Windows x64, dan macOS ARM64.
- Arsip menyertakan [Panduan Pengguna](PANDUAN-PENGGUNA.md) dan [Panduan Paket](PANDUAN-PAKET.md).

## Sebelum mencoba

- Pasang FFmpeg secara terpisah untuk format non-WAV, video, denoise, batch, dan ekspor MP4.
- Ini build preview, bukan installer final. Uji perangkat audio, latensi, pembaca layar, lisensi dependency, dan hasil restorasi pada materi produksi masih diperlukan.
- Simpan edit ke sesi dan ekspor sebagai berkas baru; media sumber tidak ditimpa.

Lihat [README](README.md) untuk fitur dan batasan lengkap.
